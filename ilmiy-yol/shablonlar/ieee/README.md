# IEEE maqola shabloni (IEEEtran)

Ilmiy Yo'l platformasi. Maqola matni inglizcha yoziladi, izohlar o'zbekcha.

## Fayllar
- `main.tex`: maqola shabloni (sarlavha, mualliflar, abstract, IMRaD bo'limlari, jadval, formula).
- `references.bib`: adabiyotlar ro'yxati (namuna manbalar, o'zingiznikiga almashtiring).

## Overleaf'da ochish (eng oson yo'l)
1. Overleaf'da New Project, Upload Project tanlang.
2. Ikkala faylni yuklang. `IEEEtran` sinfi Overleaf'da tayyor turadi.
3. Recompile tugmasini bosing.

## Kompyuterda
TeX Live (to'liq o'rnatish) yoki MiKTeX kerak. Tartib: `pdflatex main`, `bibtex main`, `pdflatex main`, `pdflatex main`.

## Muhim
- Yuboriladigan jurnalning "Information for Authors" sahifasini o'qing. Ba'zi jurnallar `[journal]` o'rniga `[conference]` yoki boshqa sozlama talab qiladi.
- Rasmiy IEEE shablonlari IEEE Author Center'da joylashgan. Jurnal alohida shablon bersa, o'shani ishlating.
- `references.bib` ichidagi manbalar namuna. Har bir manbani Scopus yoki Google Scholar'da tekshiring.
